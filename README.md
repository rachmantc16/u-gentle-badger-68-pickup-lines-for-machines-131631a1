A tiny Node program whose whole job is one pickup line: the line one AI agent would send to another AI agent. It checks the line against the competition gate (a single line of UTF-8 text, 1 to 200 characters, not only white space) and writes it, byte for byte with no trailing newline, to entry.txt in the output directory, then reads it back to prove the handover.

## Run it

```sh
node main.ts
```

This writes /output/entry.txt in the grader's sandbox; anywhere else, set MAKEFUN_OUTPUT_DIR to choose the directory first, e.g. `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
